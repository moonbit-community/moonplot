# MoonPlot 能力路线图

更新时间：2026-10-24。

目标是一个可用、易接入、可逐步完善的 MoonBit 画图库。Matplotlib 是能力与行为的参考，
不再要求复制其全部 API、Python 动态协议或所有参数。实现可以采用适合 MoonBit 的类型和调用方式。
以“用户能完成一个绘图任务、能复现结果”验收，不用 API 数量或测试数量推算整体百分比。

## 四个大目标

| 目标 | 用户得到什么 | 验收边界与当前状态 |
| --- | --- | --- |
| **G1：基础二维 SVG 可用版（M1）** | 折线、散点、柱状图；标题、轴标签、刻度、网格、图例；可运行多图示例 | 正在收尾：修复真实 grid 单轴错误、补四角图例，以实际出图和相关回归验收 |
| **G2：Rabbita 交互 DOM** | 在 Rabbit-TEA/Rabbita 应用中返回可组合的 DOM，响应悬停、点击和数据更新 | 用户明确新增的独立目标；当前尚未实现；先做折线/散点的端到端交互，详见[接入设计](RABBITA_DOM.md) |
| **G3：常用数据与科学绘图场景** | 日期趋势、分类对比、分布统计、热图及更复杂的组合图 | 已有大量基础实现；每次选择具体场景，补便捷入口/例子、修真实问题，逐项验收 |
| **G4：导出、接入与持续交付** | 清晰的安装和错误信息、稳定的库入口、更多输出方式、小步发布 | SVG 和源码示例已有；PNG/PDF、发布模块名、性能与平台范围按实际需求逐步补充 |

G4 的文档和质量工作随每个里程碑推进。优先完成 M1，随后推进 G2 的第一个可交互实例。
G3 不需要等全部图表参数一致才交付；其内部顺序由实际使用需求决定。

## M1：现在版本加少量特性即可使用

用户已选择“基础出图稳定、少量易用性特性”。本轮范围固定为：

1. 排查并修复先前三图工作流的真实错误。定位结果是默认 `which="both"` 时
   `grid(axis="y")` 被错误拒绝；不需要通过手动刻度绕开。
2. 为现有图例增加四角位置。默认仍为右上；保留自动/显式条目行为，每个 Axes 独立设置。
3. 提供运行后可直接保存的 Gallery，并检查实际 SVG 和渲染图；保持原有两个例子可用。
4. 通过相关新旧测试、四目标检查、接口检查；用少量现有测试冒烟直方图、图像与日期入口。
5. 记录已验收场景及限制，提交可复现的源码和预览。

逐项结果维护于[能力与验收清单](CAPABILITIES.md)；具体运行命令和结果见[M1 验收记录](MILESTONE_M1.md)。
M1 不要求独立 PNG/PDF 后端、交互 DOM、3D、动画或完整字体/TeX 排版。

## 后续如何推进

每个后续切片先明确一个用户场景、输入与输出，复用已有能力，提交前验证真实结果。
发现失败就定位并修复，不能把一个未验收的实现当完成，也不因为失败而默默停滞。
公共 API 只在有实际用途时扩充；保留现有调用可用，并在生成接口中审查变更。

当前架构为 Scene → render IR → SVG。G2 有第二后端需求时再提取共享几何/命中测试，
避免维护两套坐标和布局算法；Rabbita 依赖留在独立接入边界，核心与静态输出继续支持原平台。
