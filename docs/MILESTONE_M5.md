# M5：矩形网格与二维计数分箱

创建日期：2026-10-25。状态：**范围已确定，独立工作区实施中；M4 0.5.0 发布前不合入。**
继续复用已有静态图，目标版本 0.6.0。

## 平面标量网格

- [ ] 1D 严格单调边界的 flat `pcolor/pcolormesh`，可在整个实际矩形内 hover/click。
- [ ] `Heatmap + CellInfo` 保留原始行列、标量及双方向边界；掩码不压缩原索引。
- [ ] 同次绘制捕获真实四角及裁剪；mask/NaN/Inf、归一化拒绝和透明格没有有效值。
- [ ] 非均匀、反向边界、非线性轴、图例、CSS、更新与多图都有实际验证。
- [ ] Polygon 元数据使用原数组身份，构建采用序号／游标及验证；前置 image 或 contour 重写不串。
  不通过每格从头扫描全部记录查找，不设脆弱的耗时测试阈值。

## 二维计数直方图

- [ ] 现有无权重 `hist2d` 返回值不变；增加 `Histogram2D` kind，复用 CellInfo 双区间。
- [ ] 原计数在 Scene 分箱后保存，提示同时提供 x/y 区间和 Count；不从颜色恢复数值。
- [ ] 覆盖零计数格、最大边界进最后分箱、缺失输入、原行列和自定义提示。

## 普通柱的有效域边界

- [ ] 修复旧 bar/barh 在 Logit 上端点无效、区间却跨过有效视图时被丢弃的遗留行为。
- [ ] 复用现有分段柱区间逻辑，同次绘制与命中保持一致；已有合法端点／线性 SVG 保持逐字一致。
